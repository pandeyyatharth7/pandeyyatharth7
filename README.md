## 🚀 Featured Work

<table>
<tr>
<td width="50%" valign="top">

**🧠 AutoCodeIQ — Intelligent Autonomous Code Review System**

**Problem:** Manual code review is slow and inconsistent, and subtle bugs or vulnerability-prone patterns often slip through before merge.

**Aim:** Automate semantic-level code analysis to catch issues before they reach production.

**Solution:** Built an AI-assisted review system using Transformers, Hugging Face, and PyTorch to analyze code semantics and generate actionable feedback, integrated with Git/GitHub and CI/CD workflows for consistent pre-merge checks.

[🔗 View Project](https://github.com/pandeyyatharth7)

</td>
<td width="50%" valign="top">

**📦 Nexus Inventory OS — Industrial Warehouse Management System**

**Problem:** Multi-warehouse operations lacked a unified way to track stock, manage suppliers, and predict restock needs.

**Aim:** Build a full-stack platform for real-time inventory visibility and automated demand planning.

**Solution:** Built with React and Node.js/Express, backed by a 3NF-normalized MySQL schema and a demand engine that monitors reorder thresholds and estimates replenishment costs — with automatic SQLite fallback for cloud outages, deployed across Vercel, Render, and Aiven.

[🔗 View Project](https://nexus-inventory-os.vercel.app)

</td>
</tr>
<tr>
<td width="50%" valign="top">

**📸 OpenReframe — Single-Image Spatial Reframing Pipeline**

**Problem:** A single photo locks in one fixed viewpoint, with no way to pan, tilt, or zoom after the fact.

**Aim:** Enable virtual camera movement from a single 2D image using inferred 3D geometry.

**Solution:** Integrated Depth Anything V2 with diffusion-based inpainting to reconstruct gaps revealed during viewpoint changes, built on a CUDA-accelerated FastAPI/PyTorch/OpenCV backend with a React/Vite interface, optimized to run on an 8GB consumer GPU.

[🔗 View Project](https://github.com/pandeyyatharth7)

</td>
<td width="50%" valign="top">

**🛡️ Enterprise Risk Management System — Freelance**

**Problem:** A private client needed a structured way to log, track, and mitigate project risks across their organization.

**Aim:** Deliver a secure, role-aware system for risk tracking with analytics and reporting.

**Solution:** Built a React/Tailwind frontend with Recharts dashboards and a Node.js/Express/PostgreSQL backend featuring RBAC, JWT authentication, Excel export, and automated cron-based review monitoring.

</td>
</tr>
